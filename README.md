# Student Performance Analysis 

## About the Project
This project analyzes student performance using Python. It uses randomly generated data of 100 students to understand how study hours, attendance, assignments, and previous scores affect final scores.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Features
- Student dataset generation
- Data analysis and statistics
- Missing value checking
- Data visualization
- Correlation analysis
- Student performance classification
- Top 10 students identification
- CSV file generation

## Visualizations
- Study Hours vs Final Score
- Attendance vs Final Score
- Final Score Distribution
- Correlation Matrix
- Student Performance Distribution

## How to Run

1. Clone this repository.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

3. Run the Python file:

```bash
python main.py
```

## Output
The project generates a CSV file containing student performance data and displays different visualizations.

## Note
This project uses randomly generated data for learning and practice purposes.
